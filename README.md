#  AgentHire AI

AI-Powered Job Recommendation and Career Guidance System using GenAI, LLMs, FastAPI, and Streamlit.

---

##  Project Overview

AgentHire AI is an intelligent AI-driven job recommendation platform that helps users discover relevant jobs based on:

- Skills
- Experience
- Expected Salary
- Preferred Location

The system also provides AI-generated career guidance using Large Language Models (LLMs).

This project demonstrates modern GenAI engineering concepts including:
- Agentic AI workflows
- LLM orchestration
- Prompt engineering
- API integrations
- AI-powered recommendation systems
- Modular backend architecture

---

##  Features

-  AI-powered job recommendations
-  LLM-based career advice generation
-  Skill-based job matching
-  Remote job API integration
-  FastAPI backend
-  Streamlit interactive frontend
-  Secure environment variable handling
-  Match scoring system
-  Lightweight and laptop-friendly architecture
